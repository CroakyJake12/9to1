Installation Guide

The app handles updates itself, so you should only need to install it once.

  1. Click the “Download the Windows App” button above.
  2. When the download finishes, open File Explorer and go to Downloads.
  3. Right-click Maths.Revision.Portable.zip and choose Extract All.
  4. Open the extracted MathsRevision.Portable folder.
  5. Run the application. You can pin it to Start for easier access later.
