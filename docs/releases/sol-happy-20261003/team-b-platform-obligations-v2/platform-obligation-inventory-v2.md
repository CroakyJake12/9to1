# Platform inheritance inventory supplement

This supplements the earlier matrix without changing it. The earlier 310-term scan omitted mandatory LE-14 paragraph **1380244** and framework paragraph **93344**; that scan is a source index, not an obligation denominator.

The JSON retains every clause from all 15 LE groups, full General/common/framework/app rules, complete product sections and full TerraForm source in its pinned literal-source companion. No inherited obligation depends on a keyword match. It routes each mandatory rendered/input/state/restart/permission/failure/package criterion to actual product/platform scopes, source-pinned view contexts, canonical owner, browser consumer and maintained hosted authority. Every unverified route is **NOT_RUN**. A bounded native or browser case cannot establish all-app/all-mode acceptance.

| Inherited checks | Required evidence |
| --- | --- |
| Populated desktop; narrow/touch; keyboard only; screen reader | Real rendered owning app and its declared modes, canonical data and actual input/assistive technology |
| 200% scaling; theme/contrast; reduced motion; non-colour state | Actual framework capability and app usage, reachable controls and preserved domain state |
| Selected, loading, empty, error and overflow | Inspect actual rendered states; provider failure/loading must retain truthful owner results |
| UI/API journeys; restart; denial/revocation; interruption/retry/recovery | Actual canonical IDs, revisions, current permissions and durable state on each declared platform |
| Package/platform and exact release artifacts | Real trusted install or authenticated browser/no-local-Home, exact commit/hash and applicable install/upgrade/dependency failure/repair/rollback |
| Resource reliability | Actual hardware, dataset, tab counts, timing, memory/storage and bounded incremental work; absent budget needs measured proposed baseline, not an invented pass |

The complete LE-14 linked Cards/Study/RevisionBank/Planner journey and temporary/local/device/cloud privacy journey have separate explicit target/owner routes. Launcher remains Android/9to1-OS home launcher only. Mini Computer retains its exact current hosted-compute web exemption and re-evaluation requirement. Neither narrows unrelated platform criteria. All other already-supported client obligations remain active.

This is coverage inventory. It asserts no acceptance percentage, browser parity, package readiness or Lunar Eclipse completion.
