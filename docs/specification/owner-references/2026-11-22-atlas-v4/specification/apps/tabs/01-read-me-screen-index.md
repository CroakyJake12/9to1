# 9to1 Spec — App interaction reference

This native volume is a binding part of the [9to1 master specification](https://docs.google.com/document/d/1DoTJEvTbrzXWYvFu2XLswItDW1sIYbQ-7Mw7mkHt8Pk). It extends the existing feature and runtime requirements with control-level interaction behavior. The master’s chapters 11–14 define shared input patterns, Haven/Home/Settings controls, Comic and the normative volume index. Later explicit owner decisions and the master’s authority rules remain in force.

Use [Interaction records](https://docs.google.com/document/d/1tBC60DTC70QAZha8o7wn1SvgK1V3qL6vvKxDapYExl0/edit?tab=t.kh6hghkncf6x) for exact mouse, context-menu, drag, keyboard/touch, state and integration requirements. Use [Control bindings](https://docs.google.com/document/d/1tBC60DTC70QAZha8o7wn1SvgK1V3qL6vvKxDapYExl0/edit?tab=t.d6rtwhgxqmna) to find the record for a particular screen/control. A menu or visual-only field can have a target contract even where the old Atlas did not implement a handler.

Source baseline: [editable Interface Atlas v3.3 at pinned repository revision](https://github.com/CroakyJake12/9to1/blob/1f92cd888f59025cc684f0720163efdbc580f8e3/docs/specification/owner-references/2026-11-18-interface-refactor/design/9to1_Interface_Atlas_v3.3_Editable.html) and the owning chapters of the master. Sample names, prices, capabilities and historical labels in the Atlas are fixtures. Bind commands to real stable identities and current policies. Static coverage is not native/runtime execution acceptance.

Shared behavior: inherit [IX-BASE-001](https://docs.google.com/document/d/1DoTJEvTbrzXWYvFu2XLswItDW1sIYbQ-7Mw7mkHt8Pk/edit?tab=t.j832uc9l5tk#heading=h.42wlfc207wc6)–015 for basic inputs and [IX-HOST-001](https://docs.google.com/document/d/1DoTJEvTbrzXWYvFu2XLswItDW1sIYbQ-7Mw7mkHt8Pk/edit?tab=t.j832uc9l5tk#heading=h.aseep3t4mi4o)–019 for host chrome. A control-specific rule refines a shared default only for that control. Read-only/Take actions remains separate from editor Edit/View mode; choosing a model remains separate from loading it; context drafts apply only through their named commit. Study, Translate and Actions are Spaces. Home Launcher retains compatibility route launcher. Comic replaces Cinematic under the owner’s visual amendment.

Dynamic targets: the binding register records visible Atlas control occurrences by label and where available source ordinal. Repeated object rows are templates keyed by real IDs, not hard-coded sample names. A late result, reordered row or stale menu must not redirect a command to a different target. Supplemental semantic fields/regions are explicitly target contracts, not claims that the pinned screenshot contains working native controls.
