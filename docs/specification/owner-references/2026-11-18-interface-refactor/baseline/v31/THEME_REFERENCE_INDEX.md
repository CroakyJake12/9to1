## Implementation boundaries

Keep existing theme IDs and saved preferences intact until a documented owner decision resolves a mapping. Retain the normative Professional annex and the baseline appearance restrictions, including the existing Frosted Glass no-Gaussian/Mica wording. Preserve authored colours, document fonts and source imagery; chrome effects must not leak into content. Translate material cues into original shared CUI primitives/resources, not screenshots as UI, copied branding, or unrelated third-party features. Check image provenance/licensing before any asset reuse; author original assets instead of extracting third-party screenshot graphics.

For each implemented theme record source files, applicable authority, component/material changes, state coverage, accessibility/performance fallback and real before/after captures. When vision is unavailable, keep visual acceptance pending rather than claiming a match from filenames or layout coordinates.
