# Sites browser authoring

`Sites.cui`, `SitesBrowserController` and `SitesBrowserRoute` provide the actual `app.sites` destination for website list/create/open, page creation, paragraph creation and text editing. Browser presentation consumes the unchanged canonical `SiteProject`, page/component identities, `SiteSourceBinding`, schema and revision through host-retained `SitesBrowserOperations`. It supplies no API URL, actor, Files source directory, grants, default issuer or publishing service.

The composition root supplies each authenticated owner delegate, parses the embedded document and registers `new SitesBrowserRoute(ownerOperations, document)` with `registry.Register(route, route.CreateSurface)`. Optional deep-link state is `EntityType="site"` and the canonical SiteID GUID. Dispose the route on private account reset and the returned surface lifetime on close. Unsupported deployment/object actions fail before opening. The Web project consumes the portable unchanged model source link in `Contracts/NineToOne.Sites.Browser.Contracts.csproj`; native local tests consume the actual Sites owner assembly instead.

Edits retain the current owning project revision and source identity. A successful update must return the same SiteID/ProjectID/Files source binding and exactly the next owning revision. Conflict/validation rejection keeps the draft. The canonical Sites authoring API has no generic operation-key protocol, so an unknown mutation receipt disables repeated saves and changed intent until explicit reload of owner state. A foreign receipt cannot acknowledge the submitted edit. Current access denial clears the whole private project/page/component/draft view. Lists and graph rows remain bounded and use explicit CUI bindings without reflection.

The surface edits semantic text content. It does not claim a complete visual canvas, responsive editor, hosted preview, deployment, verified domains/TLS, imported code execution or full donor parity. The canonical `SiteDocumentRenderer` distinguishes public/page/component previews from `EditorShell`; a normal retained authoring scene was not materialized in this candidate. These operations therefore do not create a replacement browser canvas. The real renderer/build/HTML import are independently exercised through the native local owner tests.

`Tests/SitesBrowser.Tests.csproj` is a custom executable. Expected 13 suite cases, including independent seed and verify processes (each expected one process case). It uses the actual operating-system principal, Home profile/ownership store, `NativeFilesWorkspaceService` explicitly chosen empty-folder setup, canonical Files provider/directory mappings, native Sites workspace projection, actual resource resolvers, Home approval/broker and `SiteNativeWriteCoordinator`. Each reviewed local write is explicitly approved by the test driver; this approval is not production or hosted authority. No provider is replaced by a mock or in-memory store. Reply fault cases discard/alter receipts after a real durable owner commit.

```sh
dotnet run --project apps/Web/Sites/Tests/SitesBrowser.Tests.csproj -- suite /absolute/isolated/evidence/data
```

Independent processes compare the full canonical project serialization, SiteID/ProjectID/page/component/source IDs, revisions, schema, actual Files store/location/profile/folder identity, persisted index SHA256, renderer output and built artifact integrity. The artifact secret scan remains false when no real scanner is registered; no publishing/security gate is fabricated. The format case checks canonical HTML conversion, JSON roundtrip, render/build equality, unknown schema preservation and unsupported import rejection. All logs and source inputs must be preserved, including real owner failures.

Root owns project/resource/composition edits and shared SDK/browser execution scheduling. Backend-local/native-process evidence, local HTTP fixtures, actual browser execution, maintained Worker authority, hosted services and final acceptance remain separate gates. The Web default compile glob must exclude nested `Sites/Tests/**/*.cs` before integration. Legacy local identity fixtures must never become a remote browser identity substitute.

Pending navigation cancellation disposes its private controller before rendering. A renderer consumes the lease once and detaches navigation cancellation. Unsupported `DeepLink` and `ModelPickerTarget` contexts are rejected with the original request preserved. Individual presentation observer failures are traced by exception type, allowing later observers and commands to continue; they cannot change durable save success.

Teardown clears private presentation before notifying owner cancellation callbacks and disposes the token source even if a callback fails. The native suite commits a real edit, pauses its reply, injects a throwing owner cancellation callback, and checks persisted source alongside cleared private view.
