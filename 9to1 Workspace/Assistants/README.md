# Assistants and Specialists

Assistants and Specialists are shared resources. AI Studio defines and tests them; Spaces owns their conversations. Opening one from an older Assistants route should preserve its identity, membership, selected definition and current permissions.

This workspace holds the shared contracts, memory and compatibility host. Keep definition editing, starting a conversation and granting access to a source as distinct actions. A legacy executable or app ID may route into the same resource without becoming an additional source of data.

When testing a change, verify opening an existing definition, starting or resuming its conversation, and denying access to an unapproved source. Record which host performed each action.
