# Test a change to native Haven

Start with a failing or missing action on the correct route. Choose the project that owns that behaviour. Use the serial SDK allocation and guarded build for the current checkout; retain the revision, command, exit status and output.

For UI changes, install no new user package merely to test an edit. Prepare the source-built candidate and use the managed preview lifecycle. Check the same path with pointer and keyboard, at ordinary and compact width. For a persistent action, close normally and read the value back from the same profile. For appearance, inspect both mode families, another accent and high contrast.

State what the evidence demonstrates: a successful compilation, a focused test, a native interaction or a separate release/installation gate. A disposed fixture or a headless snapshot cannot demonstrate a live profile handoff.
