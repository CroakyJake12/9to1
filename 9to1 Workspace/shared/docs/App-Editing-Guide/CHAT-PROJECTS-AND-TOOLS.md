# Chat, project context and tool availability

The active Space or project and the selected conversation determine where a message goes. Use the genuine draft, attachment and response state from the Chat controller. Tool availability also depends on the current host, permissions and capabilities.

The Atlas places response settings inside the floating Options panel. Temporary is a control within Chat. Display the saved controls and effective resource scope for the chosen conversation. Switching to another app tab must preserve the originating conversation, composer state and any pending action.

Use the tool planner when exposing an actionable option. Keep background and interactive browser capability separate. Exercise a denied or unavailable action as well as a permitted action. A selection in the UI must not silently create filesystem or process authority.
