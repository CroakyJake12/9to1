# Editing a native 9to1 surface

Start in the window that actually displays the problem. Haven hosts Home, the Browse workspace and embedded app surfaces. A standalone app can enter the same owner through a different host. Identify the action, tab and owner before choosing an implementation file.

| Change | Starting point |
| --- | --- |
| Tab selection, overflow and tab height | Browse workspace CUI and its native adapter |
| Appearance controls | Home CUI, native preference source and shared CUI resources |
| Conversation layout and composer | Spaces Chat CUI, bindings and controller |
| Database migrations and profile location | Infrastructure database and lifecycle modules |

Follow the core product volume for behaviour and the Atlas screen register for appearance. On the development PC, prepare and reload the verified candidate through the managed preview. Reopen the changed surface and try the original action with the same profile.
