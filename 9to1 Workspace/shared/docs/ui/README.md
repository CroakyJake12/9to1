# Native interface guides

- The framework guide covers canonical CUI, its bindings and the host boundary.
- The appearance guide explains theme selection, display mode, numeric levels, accessibility and accent ownership.

For a layout change, inspect the running target at the relevant viewport and preserve the same source and profile across the comparison.
