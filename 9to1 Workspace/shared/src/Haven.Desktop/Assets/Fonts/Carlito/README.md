# Carlito document fallback

These four unmodified fonts are from `crosextrafonts-carlito-20130920`, licensed under the included SIL Open Font License 1.1. They provide the metric-compatible fallback used by LibreOffice for authored Calibri text. Document models retain the authored font name; CUI chrome keeps Montserrat.
