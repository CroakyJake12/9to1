# Canonical CUI source-build task

`CakeOS.Cui.Build.Compiler` is development infrastructure for .NET SDK 10 MSBuild. Import the compiler's `buildTransitive/CakeOS.Cui.props` and `.targets` from a source checkout. The imports add a build-only toolchain reference, discover the declared CUI source roots, compile the complete source set before resource/assembly compilation, reject legacy app markup, and embed `CUI.Compilation.v1`.

The internal `cui-build-compilation` format version 1 records source hashes, the compiler assembly hash, actual compiler language/runtime/registry metadata, typed output, source maps and dependencies. It is not AXAML, generated application code or proof of runtime acceptance. Current runtime callers still bind through their existing runtime interfaces; consuming this serialized artifact directly is separate runtime work. Canonical compiler limitations, including complete cross-file definition expansion and automatic required-capability inference, remain compiler conformance gaps rather than being reimplemented here.

`CuiSourceRoot` declares discovery roots. `Cui` supplies explicit additional sources. `CuiRequiredCapability` supplies required runtime capabilities to the compiler contract. `CuiCompilerTaskAssembly` plus `CuiUsePrebuiltCompiler=true` may select a prebuilt, compatible toolchain (used by isolated MSBuild tests); a missing task or unsupported host is an error. Failed compilation leaves the previous artifact intact, returns no success artifact and fails the build. Every invocation recompiles the snapshot, including after input removal; it never accepts stale hashes as a current result.

The legacy netstandard task ABI is retained for tooling compatibility, but its old postcompile method fails with an actionable migration diagnostic rather than falsely claiming validation. Resource-bundle collection remains a byte-preserving packaging API; it no longer runs a duplicate lexical parser or applies an obsolete root-tag rule. The legacy public lexical helper remains for ABI compatibility, outside the active compilation/packaging path. The donor source-build machinery is not scanned as application source. These source-checkout targets do not yet constitute a redistributable NuGet toolchain package.

Run the focused integration checks through `python3 ../Build.Tasks.Tests/verify_msbuild.py --task-assembly bin/Debug/net10.0/CakeOS.Cui.Build.Compiler.dll --evidence /absolute/evidence/path` from this directory after building it with the guarded local dotnet wrapper. The verifier records all command output and true exit codes; it never invokes an unguarded SDK build.
