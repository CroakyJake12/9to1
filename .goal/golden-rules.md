- Current owner instruction: develop autonomously; stop at an **observed 5% remaining usage**.
  Never substitute context length or a forecast for allowance. No reliable allowance API discovered
  at setup; the value is UNKNOWN.
- Current owner instruction and AGENTS.md: canonical `main` only; preserve every existing change,
  commit validated units, push and verify. No force pushes, reset, history cleanup or new worktrees.
- Overnight handoff: Boards/Files before the next ARM package; package held until the menu works;
  preserve Browse WIP separately and do not infer permission to include it in a package.
- AGENTS.md and canonical specification: CUI owns presentation and actions; one shared app
  implementation; no FluentTheme fallback; stable data, revision checks, undo and persistence.
- Reviewer feedback: pin the user flow before edits; compile each edit unit; real failures stay
  recorded; label tests, component rendering, native captures and owner observations distinctly.
- Resource rules: serial bounded SDK work, memory/disk reserves, no unrelated process signals,
  model restart or private-ledger fabrication. Full independent acceptance remains paused.
- Goal continuity: reread current source and checkpoint before each cycle. Never overlap source
  writers or claim scheduled/native execution without a successful supported tool receipt.
