# Wine compatibility donor source

Canonical Wine repository https://gitlab.winehq.org/wine/wine and its GitHub mirror https://github.com/wine-mirror/wine (`master`) are recorded separately; controlled fork https://github.com/CroakyJake12/wine is pinned to mirror commit `1977760e3745c58ee9c2b8aeb93e54e5fe7f14e2` (selected 2026-09-24 UTC). Actual unmodified Wine source is at `Source/Wine/`, with LGPL-2.1-or-later `LICENSE` and `COPYING.LIB` retained. No patches. The existing Wine broker still requires a separately managed runtime and has not run this donor source.
