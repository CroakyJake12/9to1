## Launch/editor matrix

APP-AC-009 and LAUNCH-001–006 apply to Write, Present, Data, Canvas, Boards, Picture, Wave, Motion, Forms, AI Studio and every later product that specifies a launch screen. Both relevant native and browser entrypoints must be checked. For every app above, actual launch without restore, direct artifact bypass, create/open/import, return-to-start/resume, cancellation/failure, unsaved/undo/selection preservation and inactive-view focus/shortcut/accessibility isolation remain NOT RUN on the new exact packaged artifact.

A Recent header, welcome overlay or source-level boolean over an otherwise active editor does not satisfy this matrix. Separate composed views may retain the same canonical session and engine. No navigation step authorises implicit close/discard/save-over. New category layout design requires the approved DESIGN-001 comparison/blueprint; syntactic migration and observed runtime equivalence are not that product-design acceptance.
