This is a dated teacher-reported scope, not a change to official 9MA0 syllabus. Scope for another exam must be checked afresh.

Teaching characteristics:
- Student prefers derivation and conceptual reason before memorizing equations.
- For horizontal transformations `g(x)=f(x+a)` explain that the input must compensate; for `f(5x)` x-distance compresses. Previously independently demonstrated.
- Basic circles, logarithms and exponential models have visible successful prior examples; do not waste a whole session reteaching unless new mistakes emerge.
- Revisit algebra manipulation and restrictions; differentiate equation transformations from factorising an expression. When `x^2=a` is solved, check both allowed roots (when applicable).
- Calculus: emphasize inverse relationship, `+C`, definite vs indefinite and chain rule; recognize when substitution vs parts applies. Do not assume IBP is a priority for the current Pure mock.
- Use the format: **Key facts/why → one challenging multi-part question → stepwise marking → progress update**. If the student asks for a compact formula digest, provide it without losing domain conditions.

Accuracy: verify solutions via reverse substitution/differentiation whenever possible, annotate extraneous roots and valid domains. Do not confuse an imported explanation with demonstrated mastery.
